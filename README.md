# @verra/design

Дизайн-система экосистемы Verra: палитра, шрифт Fixel, шкала текста, семьи
элементов (кнопки, поля, пилюли, табы, модальное окно, спиннер, тени) и
тесты-стражи, которые не дают этому расползтись.

Выросла из Metriverra (marketing-intelligence-hub); история каждого правила —
в `DESIGN_SYSTEM.md` рядом.

## Подключение

```bash
npm i github:dimatany/verra-design#v0.1.0
```

В globals.css продукта, ПОСЛЕ `@import "tailwindcss";` (нужен Tailwind v4):

```css
@import "@verra/design/index.css";
```

Характер бренда заменяем: свой блок `@theme` ниже импорта переопределяет
значения токенов — имена общие, цвета свои.

## Стражи

В `package.json` продукта:

```json
"test:design": "DESIGN_GUARD_ROOTS=src/components,src/app node --test node_modules/@verra/design/guards/*.test.mjs"
```

Настройка через окружение:

- `DESIGN_GUARD_ROOTS` — какие папки проверять (по умолчанию `src/components,src/app`);
- `DESIGN_GUARD_EXCLUDE` — подстроки путей-исключений (например, лендинг со своей палитрой);
- `DESIGN_GUARD_FIELD_ALLOW` — классы-исключения для полей (например, `inp-lvl0,inp-lvl1,inp-lvl2,inp-auto` в Metriverra, где рамка поля несёт смысл уровня бюджета).

## Правило экосистемы

**Как только правило переехало сюда — чинить его в продукте нельзя**: правим
здесь, поднимаем версию, обновляем тег в продуктах. Иначе система снова
разъедется на копии. (То же правило, что у `@verra/core`.)

Шрифт Fixel — © MacPaw, лицензия SIL Open Font License 1.1: свободное
использование, в том числе коммерческое, с сохранением имени и лицензии.

## Что здесь НЕ живёт

- Механики (вход, роли, команда) — это `@verra/core`.
- Продуктовые узоры (иерархия уровней бюджета Metriverra, полосы её таблиц,
  цвета воронки) — остаются в продукте.
- React-компоненты с поведением (Tabs, Modal, списки) — пока в продуктах:
  они сплетены с i18n и контекстом; переезд сюда — отдельный шаг.
